Store Hub — derive the app icons from logo.jpeg

Every PNG in icons/ is produced here. This is a crop and a resample of the original image — no redrawing, no recolouring, no new SVG, no AI. The logo's colours, shapes and proportions are whatever logo.jpeg already contains.

Why a browser? node has no JPEG decoder on this machine, so the decode and the high-quality resample are done by the browser's own (libjpeg + canvas). Serve the repository over HTTP, open this page, press the button, and drop the nine files into icons/. Bump BUILD in sw.js afterwards — the file names do not change, so without a new build id existing installs keep serving the previous artwork from cache.

Run: node tools/serve.mjs (or any static server) from the repo root, then open /tools/gen-icons-from-logo.html.
